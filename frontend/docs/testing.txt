1. AUTH TESTS
------------------------------------------------------------

1.1 Login with valid admin credentials
  GET  https://axis.edzlms.com/login
  Enter: admin@axis.edzlms.com / <password from credentials file>
  EXPECT: Redirect to /dashboard, AdminDashboard renders with 4 stat cards

1.2 Login with invalid password
  Enter wrong password
  EXPECT: Error toast "Invalid credentials", no redirect

1.3 Login with non-existent user
  Enter: fake@example.com / anything
  EXPECT: Same error as 1.2 (no user enumeration)

1.4 JWT refresh
  Log in, wait 15 min (or manipulate token expiry in .env for testing)
  EXPECT: Middleware auto-refreshes token, user stays logged in

1.5 Logout
  Click logout button in sidebar
  EXPECT: Redirect to /login, axis_refresh cookie cleared

1.6 Protected route without auth
  Open fresh browser, navigate to https://axis.edzlms.com/dashboard
  EXPECT: Redirect to /login

1.7 Role guard — creator cannot access /admin
  Log in as creator
  Navigate to https://axis.edzlms.com/admin
  EXPECT: Redirect to /dashboard (403 or role redirect)

API equivalent:
  curl -c cookies.txt -X POST https://axis.edzlms.com/api/auth/login \
    -H "Content-Type: application/json" \
    -d '{"email":"admin@axis.edzlms.com","password":"<ADMIN_PASSWORD>"}'
  # EXPECT: {"access_token": "...", "user": {...}}

  curl -b cookies.txt https://axis.edzlms.com/api/auth/me
  # EXPECT: {"id": "...", "email": "admin@...", "role": "admin"}

6. SECURITY TESTS
------------------------------------------------------------

6.1 AXIS_AI_KEY not in browser
  Open browser DevTools → Network tab
  Log in, navigate around
  EXPECT: No request shows the X-Master-Key or Authorization: Bearer axai_... header
  The key only appears in server-to-server calls (not visible in browser)

6.2 HttpOnly cookie
  DevTools → Application → Cookies → axis.edzlms.com
  EXPECT: axis_refresh cookie has HttpOnly flag (NOT accessible via JS)
  EXPECT: axis_access cookie visible (used by middleware)

6.3 Unauthenticated API access
  curl https://axis.edzlms.com/api/admin/status
  # EXPECT: 401 Unauthorized (no cookie)

6.4 Cross-role API access
  Log in as creator, copy axis_access token
  Try: curl -H "Cookie: axis_access=<token>" https://axis.edzlms.com/api/admin/status
  EXPECT: 403 Forbidden

6.5 Security headers
  curl -I https://axis.edzlms.com
  EXPECT:
    X-Frame-Options: SAMEORIGIN
    X-Content-Type-Options: nosniff
    Referrer-Policy: strict-origin-when-cross-origin

7. SYSTEM HEALTH CHECK
------------------------------------------------------------

Run after any deployment:

  # All services up
  for svc in nginx postgresql redis-server qdrant axis-ai axis-ai-worker axis-ai-beat; do
    printf "%-25s %s\n" "$svc" "$(systemctl is-active $svc)"
  done

  # PM2
  pm2 status

  # API health
  curl https://axisai.edzlms.com/api/v1/health
  curl -I https://axis.edzlms.com

  # SSL cert expiry
  echo | openssl s_client -connect axis.edzlms.com:443 2>/dev/null | openssl x509 -noout -dates
